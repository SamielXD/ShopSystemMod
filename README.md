# ShopSystemMod v1.4 🛒💰

A complete coin-based in-game economy system for Mindustry with **Erekir support**, **PC compatibility**, **Prestige System**, **Cosmetics**, and **Offline Earnings**!

---

## 🚨 IMPORTANT NOTICE - v1.4 UPDATE

**⚠️ THIS UPDATE WILL RESET YOUR PROGRESS! ⚠️**

Due to the new **tamper-resistant save system**, all previous save files are incompatible and will be reset to defaults. This is a one-time reset necessary to implement security features that protect against save file editing and corruption.

**Why the reset?**
- New hash-based save validation
- Enhanced data integrity checks
- Protection against tampering
- Better error handling

We apologize for the inconvenience, but this ensures a more stable and secure experience!

---

## 🌟 What's New in v1.4

### 🔐 Tamper-Resistant Save System
- Hash validation detects edited save files
- Auto-resets corrupted/tampered saves
- Value clamping prevents impossible stats
- Better error recovery

### 🌟 Prestige System
- Reset progress for permanent bonuses
- Earn Prestige Points (PP) to unlock 5 perks:
  - **Coin Master** (10 PP) → +10% coins
  - **Pet Expert** (25 PP) → +20% pet earnings
  - **Shop Discount** (40 PP) → -15% prices
  - **Wave Bonus** (60 PP) → 2x wave coins
  - **Ultimate VIP** (100 PP) → Permanent 2x VIP
- Requirements: Shop Lvl 15 & 50k earned
- Unlock exclusive Prestige Crown cosmetic

### 💤 Offline Earnings
- Pets earn coins while you're away (up to 4 hours)
- Welcome back dialog shows earnings
- VIP multiplier applies (50% rate)
- Prestige bonuses stack

### ✨ Cosmetics System
- **4 Visual Effects**: Golden Aura, Blue Flames, Rainbow Trail, Lightning
- **2 Badges**: Prestige Crown, VIP Star
- Purely visual, no gameplay advantage

### 🔨 Changes
- ❌ Removed Pet Evolution (too complex)
- ❌ Removed Daily Login (buggy)
- ✅ Pets back to simple names

## ⚠️ Known Issues

- Work system may not track progress (restart it)
- Spam-clicking can cause UI glitches
- UI odd on very small screens
- Pet missions may not update immediately
- Sound effects need files in sounds/ folder

Nothing game-breaking!

## 🔊 Sound Files Needed

Place in `sounds/` folder:
- `pop.ogg` - UI clicks
- `switch.ogg` - Menu transitions
- `coins.ogg` - Coin sounds

Mod works without them!
